# faceless-history-videos

Script JSON -> MP4, rendered for free on GitHub Actions.

Pipeline: SD-Turbo (CPU) painted backgrounds + AI cartoon head on a stickman + edge-tts Russian voice + synced captions + Ken Burns motion.

Run: Actions -> render-episode -> Run workflow -> episode path. The MP4 lands in the Releases tab.

New episode: copy episodes/plague-doctor-ru.json, change the text and bg_prompt per scene.
